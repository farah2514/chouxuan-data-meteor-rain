# 网页拼图工具

这是一个本地网页工具，支持两种导入方式：

- 直接上传多张图片
- 输入公开网页链接，提取页面中的图片后加入拼图

支持功能：

- 横向拼接
- 纵向拼接
- 调整间距、外边距、圆角、背景色
- 阴影和描边开关
- 导出 PNG

## 启动方式

确保本机安装了 Node.js，然后在当前目录运行：

```bash
node server.js
```

启动后打开：

```text
http://localhost:3000
```

## 本地测试链接

如果你想先验证“链接提图”功能，可在输入框里填：

```text
http://localhost:3000/sample.html
```

这个示例页内置了 3 张测试图片，适合快速确认提图和拼图流程。

## 说明

- 链接提图只适用于公开网页
- 某些重度动态渲染页面、需要登录的页面或强反爬页面可能提取不到
- 提取逻辑会优先保留更像内容图的大图，并尽量过滤 logo、icon 等无关图片
